# Reports

This directory is the durable reporting history for the Prime QA TCMS programme.

## Daily reports

Use `reports/daily/YYYY-MM-DD.md`.

Each report should include:

- executive summary
- objectives progressed
- completed work
- work in progress
- pull requests / repository changes
- QA and CI state
- defects or gaps discovered
- architectural/product decisions made
- blockers and decisions required from the project owner
- risks
- next actions

Reports should be evidence-based. Avoid reporting activity as progress when it did not advance an objective.
